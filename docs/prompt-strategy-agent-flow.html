失败兜底机制

五层容错策略架构

1
请求验证层

参数校验、长度限制(10000字符)、格式检查

2
安全过滤层

XSS防护、脚本注入检测、敏感词过滤

3
限流保护层

用户级/IP级限流、Redis分布式限流

4
重试恢复层

指数退避(1s/2s/4s)、最多3次重试

5
降级服务层

规则引擎默认建议、模板库默认描述

错误码体系

错误码说明可重试兜底策略
INVALID_REQUEST请求参数无效否返回参数校验错误
CONTENT_FILTERED内容安全过滤否返回安全提示
AUTH_FAILEDAPI密钥无效否需重新配置
RATE_LIMITED请求频率超限是稍后重试
MODEL_NOT_FOUND模型端点不存在否配置错误
TIMEOUT请求超时(30s)是指数退避重试
INTERNAL_ERROR服务器内部错误是重试后降级
AUCTION_NOT_FOUND竞拍不存在否业务错误提示
AUCTION_NOT_ACTIVE竞拍未激活否状态提示
INSUFFICIENT_DATA历史数据不足否使用默认策略

降级策略详情

出价建议降级

AI不可用时使用规则引擎：

  • 建议出价 = 当前价 + 步长
  • 策略默认moderate
  • 风险等级默认medium
  • 推理说明使用模板文本

商品描述降级

AI生成失败时使用模板库：

  • 从BroadcastTemplate库匹配
  • 使用默认professional风格
  • 填充基础商品信息
  • 标注"AI辅助生成"

缓存兜底

Redis缓存保障：

  • TTL: 5分钟
  • 命中率: 85%
  • 即使AI故障，缓存仍可用
  • md5(prompt+system)作为key

监控告警

AI服务健康监控：

  • 成功率 < 95% 触发告警
  • P99 > 3s 触发告警
  • 连续3次失败自动熔断
  • 30秒后半开状态恢复
