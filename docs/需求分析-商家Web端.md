# 商家Web端需求分析

## 一、项目概述

### 1.1 产品定位
"直播竞拍大师"商家Web管理端，面向B端商家，提供商品管理、竞拍管理、订单管理、直播间监控、AI智能辅助、数据分析等全链路运营管理能力。

### 1.2 目标用户
- 直播电商商家/运营人员
- 需要管理竞拍商品和直播间的商家
- 需要数据分析和AI辅助决策的商家

### 1.3 技术选型
| 类别 | 技术 | 版本 |
|------|------|------|
| 框架 | React | ^19.2.6 |
| 语言 | TypeScript | ^5.0.0 |
| UI库 | Ant Design | ^5.29.3 |
| 状态管理 | Redux Toolkit + react-redux | ^2.12.0 / ^9.3.0 |
| 路由 | react-router-dom | ^7.15.1 |
| HTTP | axios | ^1.16.1 |
| 实时通信 | socket.io-client | ^4.8.3 |
| 图表 | recharts | ^3.8.1 |
| 表单 | formik + yup | ^2.4.6 / ^1.4.0 |
| 日期 | dayjs | ^1.11.20 |
| 构建工具 | react-app-rewired (CRA) | ^2.2.1 |

## 二、功能模块详细需求

### 2.1 认证模块

#### 2.1.1 登录功能
- **需求描述**：商家通过用户名+密码登录管理后台
- **功能要点**：
  - 登录表单（用户名、密码）
  - 表单校验（非空、格式）
  - JWT Token存储（localStorage）
  - 登录成功跳转控制台首页
  - 登录失败错误提示
  - 角色校验（仅merchant角色可登录管理端）
- **接口依赖**：`POST /api/auth/login`

#### 2.1.2 路由权限控制
- **需求描述**：未登录和非法角色无法访问管理页面
- **功能要点**：
  - ProtectedRoute组件：未登录重定向至登录页
  - 角色校验：非merchant角色重定向至Dashboard
  - Token过期自动登出
  - 已登录用户访问登录页自动跳转Dashboard

### 2.2 控制台首页（Dashboard）

#### 2.2.1 数据概览
- **需求描述**：商家运营数据一站式概览
- **功能要点**：
  - 核心指标卡片：
    - 今日竞拍数
    - 进行中竞拍数
    - 今日成交额
    - 今日订单数
    - 待处理订单数
  - 趋势图表：近7天/30天成交额趋势
  - 最近竞拍活动列表
  - 最近订单列表
  - 待办事项提醒
- **接口依赖**：`GET /api/analytics/dashboard`、`GET /api/analytics/overview`

---

### 2.3 商品管理模块

#### 2.3.1 商品列表
- **需求描述**：管理所有竞拍商品
- **功能要点**：
  - 商品表格展示（名称、分类、起拍价、状态、库存、创建时间）
  - 搜索筛选（关键词、分类、状态）
  - 分页
  - 批量操作
  - 新增商品按钮
  - 编辑/删除操作
- **接口依赖**：`GET /api/products`、`DELETE /api/products/:id`

#### 2.3.2 新增/编辑商品
- **需求描述**：创建或修改商品信息
- **功能要点**：
  - 基本信息：名称、描述、分类、SKU编码
  - 价格设置：起拍价、加价幅度、封顶价
  - 竞拍设置：竞拍时长（秒）、延时时间（秒）
  - 库存管理：库存数量、库存预警阈值
  - 物流设置：重量、运费模板
  - 图片上传：多图上传，支持拖拽排序
  - 标签管理：自定义标签
  - 规格参数：JSON格式规格配置
  - AI辅助：一键生成商品描述、AI定价建议
- **接口依赖**：`POST /api/products`、`PUT /api/products/:id`、`POST /api/upload`

#### 2.3.3 商品详情
- **需求描述**：查看商品完整信息
- **功能要点**：
  - 商品所有字段展示
  - 商品图片预览
  - 关联竞拍记录
  - 关联订单信息
  - 页面浏览统计
- **接口依赖**：`GET /api/products/:id`

#### 2.3.4 分类管理
- **需求描述**：管理商品分类
- **功能要点**：
  - 分类列表（名称、图标、排序值）
  - 新增/编辑/删除分类
  - 排序调整
- **接口依赖**：`GET /api/categories`、`POST /api/categories`、`PUT /api/categories/:id`、`DELETE /api/categories/:id`

### 2.4 竞拍管理模块

#### 2.4.1 竞拍列表
- **需求描述**：管理所有竞拍活动
- **功能要点**：
  - 竞拍表格展示（商品名称、起拍价、当前价、状态、开始/结束时间、获胜者）
  - 状态筛选（待开始/进行中/已结束/已取消）
  - 搜索
  - 分页
  - 操作按钮：上架竞拍、开始竞拍、结束竞拍、取消竞拍
- **接口依赖**：`GET /api/auctions`

#### 2.4.2 竞拍详情
- **需求描述**：查看竞拍活动完整信息
- **功能要点**：
  - 竞拍基本信息
  - 实时价格和倒计时
  - 出价记录列表
  - 排行榜
  - 竞拍状态操作
  - WebSocket实时数据更新
- **接口依赖**：`GET /api/auctions/:id`、WebSocket

#### 2.4.3 竞拍操作
- **需求描述**：商家控制竞拍生命周期
- **功能要点**：
  - 上架竞拍：选择商品，设置竞拍参数，创建竞拍
  - 开始竞拍：启动竞拍计时
  - 结束竞拍：手动结束竞拍
  - 取消竞拍：取消进行中/待开始的竞拍
  - 排行榜查看
- **接口依赖**：`POST /api/auctions`、`PUT /api/auctions/:id/start`、`PUT /api/auctions/:id/end`、`PUT /api/auctions/:id/cancel`

### 2.5 订单管理模块

#### 2.5.1 订单列表
- **需求描述**：管理所有竞拍订单
- **功能要点**：
  - 订单表格展示（订单号、商品、买家、金额、状态、时间）
  - 状态筛选（待付款/已付款/已发货/退款中/已退款/已取消）
  - 搜索（订单号、买家）
  - 日期范围筛选
  - 分页
  - 导出订单数据（Excel/CSV）
  - 批量操作
- **接口依赖**：`GET /api/orders`、`GET /api/export`

#### 2.5.2 订单详情与操作
- **需求描述**：查看订单详情并执行操作
- **功能要点**：
  - 订单完整信息展示
  - 买家信息和收货地址
  - 订单状态流转操作：
    - 待付款 → 确认收款（线下支付场景）
    - 已付款 → 发货（填写快递单号、物流公司）
    - 已发货 → 查看物流
    - 退款中 → 同意退款 / 拒绝退款（填写拒绝原因）
  - 商家内部备注
  - 订单金额和退款金额展示
- **接口依赖**：`GET /api/orders/:id`、`PUT /api/orders/:id/ship`、`PUT /api/orders/:id/refund/approve`、`PUT /api/orders/:id/refund/reject`

### 2.7 AI智能助手模块

#### 2.7.1 AI聊天
- **需求描述**：通用AI对话功能
- **功能要点**：
  - 聊天界面（消息气泡式）
  - 上下文对话
  - AI服务状态指示
  - 使用统计展示
  - 缓存清理
- **接口依赖**：`POST /api/ai/chat`、`GET /api/ai/status`、`GET /api/ai/stats`

#### 2.7.2 商品描述生成
- **需求描述**：AI自动生成商品描述文案
- **功能要点**：
  - 输入：商品名称、商品类型、商品特点
  - 3种风格选择：专业型 / 活泼型 / 奢华型
  - 生成500-800字商品描述
  - 字数统计
  - 修改建议
  - 一键复制/应用到商品
- **接口依赖**：`POST /api/ai/assistant/generate-description`

#### 2.7.3 直播话术建议
- **需求描述**：AI根据竞拍状态生成直播话术
- **功能要点**：
  - 根据竞拍状态自动生成话术（待开始/进行中/已结束/已取消）
  - 3种风格选择：激情型 / 专业型 / 亲切型
  - 话术分类：开场白、出价引导、价格播报、倒计时、延时通知、结束、互动
  - 话术模板管理（CRUD）
  - 7个预置模板
  - 自定义模板（名称、内容、变量、分类）
- **接口依赖**：`POST /api/ai/assistant/broadcast-suggestion`、`GET /api/ai/assistant/templates`、`POST /api/ai/assistant/templates`、`PUT /api/ai/assistant/templates/:id`、`DELETE /api/ai/assistant/templates/:id`

#### 2.7.4 AI定价建议
- **需求描述**：AI根据商品信息给出竞拍定价建议
- **功能要点**：
  - 输入：商品名称、商品类型、目标受众
  - 输出：
    - 建议起拍价
    - 建议加价幅度
    - 定价理由
    - 置信度
    - 市场数据（均价、价格区间、竞品数量）
  - 一键应用到商品
- **接口依赖**：`POST /api/ai/assistant/suggest-pricing`

#### 2.7.5 直播脚本生成
- **需求描述**：AI生成完整直播脚本
- **功能要点**：
  - 输入：商品名称、商品特点、竞拍信息
  - 3种风格：热情型 / 专业型 / 亲切型
  - 输出5段式脚本：
    - 开场白（欢迎观众、营造氛围）
    - 商品介绍（详细介绍商品特点和卖点）
    - 引导出价（鼓励观众出价竞拍）
    - 制造紧迫感（营造紧张氛围、限时提醒）
    - 结束语（感谢参与、预告下一场）
  - AI不可用时自动降级为模板话术
- **接口依赖**：`POST /api/ai/assistant/generate-live-script`

### 3.1 性能需求

## 八、核心业务流程

### 8.1 商品上架竞拍流程
```
创建商品 → 设置竞拍参数 → 创建竞拍(待开始) →
开始竞拍(进行中) → 用户出价 → 竞拍结束 →
生成订单(待付款) → 买家付款 → 商家发货 → 交易完成
```

### 8.2 AI辅助运营流程
```
商品管理 → AI生成描述 → AI定价建议 → 应用到商品 →
创建竞拍 → AI生成直播脚本 → AI话术建议 →
直播间监控 → 实时话术推荐 → 竞拍结束
```

### 8.3 订单处理流程
```
竞拍结束 → 自动生成订单(待付款) →
买家付款(已付款) → 商家发货(已发货) →
买家确认收货(已完成)
│
└→ 买家申请退款(退款中) →
   商家同意(已退款) / 商家拒绝(已付款)
```
